AI 智能测试平台 testcase-agent 在线可访问CI 通过

独立开发者 ｜ Python · Streamlit · 多 Agent · Pytest · GitHub Actions
解决的问题：通用大模型直出的测试用例方法不可溯、质量不稳，且"生成完就丢"，无法支撑真实测试管理流程。
  • 多 Agent 流水线：「需求分析 → 测试点提炼 → 用例生成 → 独立评审」四段编排，dataclass 结构化传递，Agent 可单独替换
  • 方法论注入：显式注入等价类 / 边界值 / 场景法 / 错误猜测四类设计方法，每条用例标注 method 来源、全程可追溯
  • 评审门禁：独立评审 Agent 按 5 项标准打分（方法覆盖 / 结构 / 优先级 / 可追溯 / 边界±1），形成"生成-评审"对抗闭环
  • 业务闭环：AI 产出经人工勾选采纳入库，覆盖用例库 → 测试执行 → 测试报告 → 缺陷跟踪 → 工作台看板，ID 全局唯一可追溯
